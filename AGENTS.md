# Smart Hub handoff

Start by reading `README.md`, `docs/RESTANT.md` and, for hardware work, `docs/CADRE-WINDOWS.md`. The user’s AiMOR frame is now installed from the Mac; preserve the Windows handoff as a recovery option.

- On 2026-10-20, USB ADB root and the documented sun8i/Android 6.0.1/ARMv7/1280x800 identity were verified on the Mac. Data/boot/bootloader backups were verified before installing Firefox 143.0.4 and SimpleSSHD 27. Hub v0.7.0 is served on-device at 127.0.0.1:4173; real rendering/fullscreen and the user's basic touchscreen check passed. A real Android reboot preserved settings and files; USB/Wi-Fi returned. The firmware blocked SimpleSSHD BOOT_COMPLETED despite its approved preference; SSH was manually restored over USB, then Hub over Wi-Fi. Autostart, power-cut behavior, physical Settings recovery and long-running performance remain unverified. Read docs/MAINTENANCE-CADRE.md; never infer those checks from browser QA.
- Read the current Git status/history/remotes before changing or publishing. The public GitHub repository already exists and main is the publication branch. Keep human-readable English commits and logical semantic versions based on existing history.
- On 2026-10-21, after explicit approval of the system-file write, a reversible asynchronous hook was appended to `/system/bin/install-recovery.sh`; original bytes were backed up and `/system` returned read-only. The final real reboot restored loopback httpd, key-only SSH with its restricted firewall, and the existing single Firefox Hub tab without manual starts. HTML fullscreen still needs its button after reboot; power-cut behavior is unverified. Read `docs/DEMARRAGE-RESEAU.md` before changing startup. The frame still uses DHCP; MAC and IP changed again across reboots. Do not claim a stable IP or blindly reserve only its current MAC.
- Preserve user data. `.env`, `.data`, firmware backups, diagnostic dumps, account credentials and private device identifiers must stay out of Git. Never log OAuth tokens or API secrets.
- Device IP and MAC changed on reboot. Re-read the current IP; historic values are not defaults. Port 8086 is the AiMOR file service, not ADB.
- Start with the USB and network read-only checks, and stop if identity differs from the documented device. Verify backups before device writes. Do not flash boot/system or disable the only working launcher/access path as a routine setup step.
- ADB, a screenshot or an injected tap does not prove that physical touch or a recovery path works. Have the user verify the real touchscreen and access to Android Settings before replacing the launcher.
- Target Chrome/WebView 106+. Avoid CSS nesting, `color-mix()`, `oklch()` and `:has()` for required behavior. Native View Transitions are an optional enhancement with a color-transition fallback.
- Preserve reduced-motion behavior and keyboard focus. Keep motion short and event-driven; no perpetual render loops. Clocks update by minute, timers by second only when active, and synchronization sleeps when hidden.
- Run `npm run check`, `npm test`, then verify affected UI at 1280 × 800 and relevant narrow sizes. Test real integrations separately; never present sample data as connected data.
- Track completed and remaining work in `docs/RESTANT.md`, distinguishing local code, Git publication, service authorization and hardware installation.
