# Hub.

Tableau de bord tactile pour cadre Android : météo, agendas, tâches, recettes, musique et domotique Home Assistant.

![Accueil de Hub sur le cadre](docs/images/hub-accueil.png)

```sh
git clone https://github.com/KillermyB/smart-hub.git
cd smart-hub
npm start
```

Node.js 22.9+ · Ouvrir http://localhost:4173 · [Configuration](docs/CONFIGURATION.md) · [Guide complet](docs/GUIDE.md)

Un grand merci à **[Wes Bos et aux contributeurs de photo-frame-dashboard](https://github.com/wesbos/photo-frame-dashboard)** : leur travail sur les cadres Android et les réalisations de la communauté ont inspiré ce projet.

Les clés, jetons et exports privés restent hors du dépôt. Les licences des ressources tierces sont conservées dans `dist/licenses/` et `dist/fonts/`.
