# Recettes petit budget, sans porc

20 versions simplifiées, rédigées pour le carnet, pour deux personnes. Le catalogue initial compte désormais 32 recettes, hors ajouts personnels.

La sélection privilégie légumineuses, œufs, légumes de saison ou surgelés et conserves de poisson. « Petit budget » est une sélection qualitative : aucun prix par portion n’est garanti et les prix varient selon les magasins. Les durées et ingrédients adaptés peuvent différer de la recette source.
